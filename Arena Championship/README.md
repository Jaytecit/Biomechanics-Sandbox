# Arena Championship

Standalone showmanship app for finished soft-body models.

- **Sandbox** (`../`): design, evolve, freeze & name models
- **Arena Championship** (this folder): events, heats, podiums, leaderboards

## Run

From the parent `Build an Agent` folder (same Vite server, shared `localStorage`):

```bash
npm run dev
```

Then open:

- Sandbox: http://localhost:3000/
- Arena: http://localhost:3000/Arena%20Championship/

## Flow

1. Evolve in the Sandbox
2. **Freeze & Save** a finished model
3. Open Arena Championship → pick an event → select roster → **Start heat**
